# Guide de mise à jour - Ajout des icônes aux liens

## 🛠️ Étapes nécessaires

Pour utiliser le nouveau sélecteur d'icônes dans admin/links, vous devez d'abord mettre à jour la structure de la base de données :

### 1. Accéder à admin/links
- Allez sur `http://localhost:5173/admin/links`

### 2. Ajouter la colonne icon
- Dans la section "État de la base de données" 
- Cliquez sur **"Ajouter colonne icon"** (bouton bleu)
- Attendez la confirmation de succès

### 3. Utiliser le sélecteur d'icônes
- Cliquez sur **"+ Nouveau lien"**
- Vous verrez maintenant un nouveau champ "Icône"
- Cliquez dessus pour ouvrir le sélecteur avec 60+ icônes Phosphor
- Recherchez par nom d'icône
- Sélectionnez l'icône désirée

### 4. Modification des liens existants
- Cliquez sur l'icône crayon ✏️ d'un lien existant
- Le modal s'ouvrira avec le sélecteur d'icônes
- Modifiez l'icône et sauvegardez

## ✨ Fonctionnalités ajoutées

- **Sélecteur d'icônes** : 60+ icônes populaires (réseaux sociaux, tech, etc.)
- **Recherche d'icônes** : Tapez pour filtrer les icônes
- **Aperçu en temps réel** : Voir l'icône sélectionnée
- **Modal fonctionnel** : Ajout et édition maintenant opérationnels
